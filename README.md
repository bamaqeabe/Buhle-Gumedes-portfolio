# Buhle — Personal IT Portfolio

A responsive personal portfolio website to introduce Buhle, an Information Technology student and aspiring developer. It displays an introduction, about, skills, selected student projects, education and contact form with client validation.

## Technologies used

- HTML5 — semantic page structure and accessible form labels.
- CSS3 — responsive layouts, custom visual design, theme variables and mobile/tablet breakpoints.
- JavaScript — mobile navigation, dark/light theme switch, project category filters, contact form validation and dynamic copyright year.
- Google Fonts — DM Sans and Playfair Display typography, loaded from Google Fonts.

No JavaScript framework or CSS framework is required.

## Features

- Hero section for home/introduction and personal branding.
- About Me section and learning goals.
- Skills grouped by web development, programming, databases, working style.
- Project cards with JavaScript category filters.
- Education and learning journey timeline.
- Contact form with required field, email format and minimum length validation.
- Mobile navigation menu.
- Toggle between dark/light theme.
- Responsive layout for desktop, tablet and mobile.
- Accessible form labels, focus styles and status feedback.

## Run locally

1. Download or clone this repository:
```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY-NAME.git
```
2. Open the project folder.
3. Open `index.html` in a web browser.

No build tools or package installation are required. An internet connection is needed to load the Google Fonts; the website otherwise works locally.

## Publish with GitHub Pages

1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Copy the published URL into the Live website section above.
7. Open the URL in a private/incognito window and test all navigation links, filters, theme switch and form validation.
